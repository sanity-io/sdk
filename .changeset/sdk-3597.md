When the authorization server refuses an OAuth sign-in, the error in the `ERROR` auth state is now an `OAuthError` whose `code` and `description` hold the server's `error` and `error_description`, so an app can tell an account without access (`invalid_target`) from other failures. `LoginError`, the screen `AuthBoundary` shows by default, is exported, so a `LoginErrorComponent` can show its own screen for some errors and the default for the rest.
