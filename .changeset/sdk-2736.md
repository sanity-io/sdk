---
'@sanity/sdk-react': patch
---

SDK apps hidden by React `<Activity>` keep working when shown again, instead of crashing on a disposed Sanity instance. Unmounting `SanityApp` no longer disposes its Sanity instance. To dispose it yourself, for example between tests, create the instance with the same config and render `SanityApp` inside `<SanityInstanceProvider instance={instance}>`, then call `instance.dispose()` when you are done.
