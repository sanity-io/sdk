Preference hooks take `shared: true` to read and change the value everyone in a project or organization shares, for keys that have one, and `resourceType` to pick a project or an organization for a key stored in both. A preference says whether its value is the default (`isDefault`), shared (`shared`) or stored in a `resourceType`, and `canEdit` says whether the signed-in user can change it.
