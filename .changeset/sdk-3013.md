Each message bus connection has a `key`, sent with every message, and can name the key of the connection that rendered it as its `parentKey`. When the Dashboard renders an app inside another app, the app connects with that parent, and the Dashboard hears it only while it hears the parent.

The SDK now reads an app's module id from the root context the Sanity CLI provides, not the separate module context. Update the Sanity CLI and the SDK together: with only one of them updated, an app connects with its app id instead of its module id.
