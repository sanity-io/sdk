`useUserPreference` reads a signed-in user's preference, like a list's layout, and `useUpdateUserPreference` changes it: pass a value, a function of the value on screen, or `undefined` to go back to the default. A change shows at once, sticks across reloads and browsers, and goes back if the API refuses it.
