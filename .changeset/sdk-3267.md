`useApplications` reads an organization's applications a page at a time: `loadMore` adds the next page to `data.data`, `hasMore` says whether there is one, and `isPending` is true while it loads. A failed `loadMore` keeps the applications already shown and sets `error`. The `cursor` option is deprecated.
