An application's `icon`, and an installation's `application.icon`, is the URL of an image on `cdn.sanity.io`. The API no longer returns SVG markup, so render it as an `<img>`. Studio workspace `icon` is still SVG markup. `updateApplication` no longer takes `icon`, since the API sets it on deploy. The applications API is experimental, so this change ships in a minor.
